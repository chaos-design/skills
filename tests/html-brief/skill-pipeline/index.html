Rules that hold everywhere

Key point

Each skill writes only under its own tests folder, and never moves or renames another skill's output.

  • A skill that needs another skill asks before installing it and shows the exact npx skills add command.
  • A missing runtime dependency is reported as a blocked test, never replaced with mock or placeholder output.
  • Generated dates use UTC+8 in the format YYYY-MM-DD HH:mm:ss.
  • Preview links in tests/index.html are added, never rewritten.
