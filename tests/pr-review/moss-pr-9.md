### 后端适配器

1. **fishaudio 非 ASCII `model` 触发未处理 500** — `backend/services/fishaudio/client.py:104`、`:169`。`_parse_model` 只校验长度 ≤120（`app.py:73-79`），随后 `headers={TTS_MODEL_HEADER: model}` 直接把用户输入放进 HTTP 头；非 ASCII 值（如 `{"model": "中文模型"}`）会让 httpx 抛 `UnicodeEncodeError`——它不是 `httpx.RequestError`，绕过现有 except，经 `asyncio.to_thread` 冒泡成未处理 500 而非统一错误 JSON（已用 TestClient 复现）。建议在 `_parse_model` 拒绝非 ASCII/不可打印字符（400 invalid_model）。
2. **Bearer token 含非 ASCII 时鉴权返回 500 而非 401** — `backend/services/elevenlabs/app.py:42-49`、`backend/services/fishaudio/app.py:42-49`。`hmac.compare_digest(token.strip(), settings.access_token)` 的 str 形式要求双方均为 ASCII；非 ASCII token（ASGI 头按 latin-1 解码，可达此处）抛 `TypeError` → 500 + 完整 traceback（已用裸 socket 复现）。虽"失败关闭"无鉴权风险，但破坏错误契约并刷屏日志。建议改按字节比较：`hmac.compare_digest(token.strip().encode(), settings.access_token.encode())`。
3. **413 文案硬编码 "8 MB"** — `elevenlabs/app.py:341`、`fishaudio/app.py:316`。上限实际可配（`MOSS_*_MAX_AUDIO_BYTES`，1_000–32_000_000），超限时提示固定为 8 MB。建议插入 `settings.max_audio_bytes`。
4. **`test_speech` 对 `text`/`input` 的 null 处理不一致** — `elevenlabs/app.py:271-275`（fishaudio 同构）。`{"input": null}` 被 `value is not None` 过滤、落到默认探测文本；`{"text": null}` 却因 `if "input" not in payload and "text" in payload` 原样写入 `merged["input"]` → 400 invalid_text。建议判断改为 `payload.get("text") is not None`。
